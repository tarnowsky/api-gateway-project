🎓 University Microservices API

A modern, scalable microservices architecture demonstrating cloud-native development practices with user management, product catalog, and order processing capabilities.

🌐 API Gateway Live

All requests are routed through our API Gateway running on port 8080

Base URL: http://localhost:8080
Rate Limit: 100 requests per 90 seconds
Timeout: 30 seconds

🔐
Authentication

Most endpoints require JWT authentication. Include the token in the Authorization header.

# Login to get token
curl -X POST http://localhost:8080/users/login \
  -H "Content-Type: application/json" \
  -d '{"username": "your_username", "password": "your_password"}'

# Use token in requests
curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  http://localhost:8080/users/profile
👤
User Service
Port 3001

Handles user registration, authentication, and profile management with JWT token-based security.

POST /users/register
Register a new user account • No Auth Required
POST /users/login
Authenticate user and receive JWT token • No Auth Required
GET /users/profile
Get current user profile • Auth Required
GET /users
List all users (admin endpoint) • Auth Required
📦
Product Service
Port 3002

Manages product catalog with full CRUD operations, filtering, and category management.

GET /products
Get all products (supports category & stock filters) • Auth Required
POST /products
Create new product • Auth Required
GET /products/:id
Get specific product details • Auth Required
PUT /products/:id
Update product • Auth Required
DELETE /products/:id
Delete product • Auth Required
🛒
Order Service
Port 3003

Handles order processing, status management, and provides order analytics with user-specific access control.

POST /orders
Create new order • Auth Required
GET /orders
Get user's orders • Auth Required
GET /orders/:id
Get specific order details • Auth Required
PATCH /orders/:id/status
Update order status • Auth Required
DELETE /orders/:id
Cancel order • Auth Required
GET /orders/stats/summary
Get order statistics • Auth Required
